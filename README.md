# PurseWash Source Code
* Server Folder:
  Refers to the list of scripts the server uses to function
* Client Folder:
  Refers to every program that can interact with the servers whether to read, or request data for a backend server. Free to use by public
* Encrypted Folder:
  Reffers to server and backend server data and/or scripts that is exclusive to those only
* Data Folder:
  Refers to free to read and free use data
